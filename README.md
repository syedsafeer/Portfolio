# Syed Safeer Abbas Naqvi - Personal Portfolio

This is a fully responsive personal portfolio website built with:

- HTML5
- CSS3 (custom design system with variables)
- Vanilla JavaScript

## Files

- `index.html` - semantic structure and sections
- `styles.css` - custom responsive styling and layout
- `script.js` - dynamic rendering, filtering, smooth scroll, and navbar behavior

## Run Locally

Open `index.html` in a browser.

If you want to run with a local static server (optional), use one of these:

```powershell
python -m http.server 8080
```

Then visit:

- `http://localhost:8080`
